An animal in three sizes: tile for opponent pods, chip for your hand, lot card for the animal up for auction.

**Replaces** `AnimalCard.tsx` (`chip` / `card`) and the `.animal` styles.

**Rules** — the animal's colour token (`animal-horse`…) sits only behind the art. Name and value sit on a `paper` strip; counts sit on a `paper` badge. Completed sets of four get a `set-gold` ring and the word "Set" (chip) or a gold badge (tile). Always `ink` outlined.

**Consumer provides** — the `Animal`, an optional count, and whether it's a complete set.
