A banknote from the original art set: 0, 10, 50, 100, 200, 500, and the face-down back.

**Replaces** `MoneyNote.tsx` and the money picker button styles.

**Sizes** — 64×36 standalone, 56×31.5 in the hand, 40×22.5 in overlays, 20×11 as the money-count icon in pods.

**States** — `.kh-noteb` wraps a note as a toggle; `aria-pressed="true"` lifts it 7px with an `accent` ring and `lift-lg`.

**Rule** — face-down backs are used wherever a value is hidden: cow-trade offers on the stage and other players' money counts.
